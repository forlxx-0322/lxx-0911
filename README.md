# 客户管理系统（阀门行业版）

面向阀门销售的个人客户与项目管理软件。**单机运行、无需登录、数据全部留在本机**，
双击 `启动.bat` 即用。

当前版本 **1.10** · 详见 [CHANGELOG.md](CHANGELOG.md)

---

## 特点

- **零依赖**：后端只用 Node.js 内置模块（`node:sqlite` + `node:http`），
  前端 Vue 3 / ECharts / SheetJS 全部内置于 `web/vendor/`。
  **无需 `npm install`，无需任何联网配置，离线可用。**
- **无需登录**：个人自用，没有账号体系。
- **数据不出本机**：服务只监听 `127.0.0.1`；除招标采集模块（默认关闭）外，
  全程零外部网络请求。
- **真实 Excel**：导出为 `.xlsx`（中文不乱码、数值可参与计算），导入带校验与预览。

## 快速开始

1. 安装 [Node.js](https://nodejs.org/) 20 或更高版本（本项目在 v24.21.0 上开发验证）
2. 双击 **`启动.bat`** —— 会自动建库、启动服务并打开浏览器
3. 关闭那个黑色窗口即停止服务；也可双击 **`停止.bat`**

数据存放在 `data/` 目录（数据库、附件、备份）。想直接打开该目录可双击 `打开数据目录.bat`。

## 功能模块

| 模块 | 说明 |
|---|---|
| **首页总览** | 6 张数字卡 + 客户分布地图 + 趋势/阶段/行业/漏斗 4 张图表 + 待跟进、回款、招投标日历、待办、动态 |
| **客户管理** | 8 区块 60 字段（阀门行业定制：最终用户、设计院、阀门类型、认证要求、账期…）；联系人、跟进、标签、查重、回收站、批量导入导出 |
| **项目管理** | 14 阶段看板、项目详情、回款计划与实收登记（欠款/回款率自动计算） |
| **待办中心** | 跟进计划、回款提醒、手动待办汇总到一处 |
| **招标采集** | 在各招标平台订阅关键词邮件，本地解析成项目线索（**默认关闭**，需自行配置邮箱；详见下方） |
| **功能设置** | 字典管理、标签、提醒偏好、备份恢复、导入导出、附件存储、回收站、操作日志、关于 |

## 地图

首页渲染新疆地州级矢量地图（24 个地州级要素，含兵团市），边界为本地 GeoJSON，**断网可用**。

- 客户填了「市/地区」后**自动归属**到地州（也支持只填区县，或把县级市填在市字段里）
- 支持手工录入经纬度精确定位，内置 WGS84 ↔ GCJ-02 ↔ BD-09 坐标转换（纯本地计算）
- 点击地州可下钻到县市，点击区域显示该区客户清单

## 招标信息采集（可选，默认关闭）

软件里**唯一会联网的模块**。走「邮件订阅解析」路线：你在各招标平台订阅关键词推送，
软件本地读邮件（IMAP）解析成项目线索——**不抓取任何网站**。

- **默认关闭**：未启用任何来源时不产生任何外部网络请求
- **只读邮箱**：使用 `EXAMINE` + `BODY.PEEK`，不把邮件标记为已读、不改动邮箱任何状态
- **不采集个人联系方式**：公告里的姓名/手机号/邮箱一律不入库，
  只提示你点原公告自行查看
- **人工审核**：采集结果先进暂存区，确认后才写入项目库，并保留来源链接可回查
- 调度规则：每 24 小时采集一次，有更新则更新、无更新不动

配置方式：招标采集 → 采集来源 → 新增，填邮箱账号与**授权码**（不是登录密码，
界面里每个邮箱服务商都写了获取路径）。

## 批量导入客户

客户管理页右上角 → **批量导入**：

1. 下载模板（`.xlsx`，含「导入模板 / 填写说明 / 可选值参考」三页）
2. 按模板填写，拖回抽屉
3. 先校验预览（哪行有问题、为什么），确认后导入

重名的行可选**跳过**或**更新已有记录**（更新时只覆盖表格里填了的列，留空的保留原值）。

## 备份与恢复

- 每天首次启动自动备份：主目录保留 30 份，镜像目录保留 7 份
- 设置 → 备份与恢复：可手动备份、校验完整性、从备份恢复（恢复前自动再做一次兜底备份）
- ⚠ 附件存放在 `data/attachments`，**不包含在数据库备份里**，换机时需一并拷贝

## 目录结构

```
├─ 启动.bat / 停止.bat / 打开数据目录.bat   启动器
├─ server/            后端（零依赖）
│  ├─ server.js         服务入口、路由分发、静态文件
│  ├─ db.js             建表、结构版本与迁移
│  ├─ services/         客户、项目、回款、待办、备份、Excel、附件
│  ├─ collect/          招标采集（IMAP 客户端、MIME 解析、信息抽取、引擎）
│  ├─ map/              地图数据与坐标转换
│  └─ routes/           各模块接口路由
├─ web/               前端（全部本地文件）
│  ├─ index.html
│  ├─ css/app.css
│  ├─ js/               页面、组件、主题、路由
│  └─ vendor/           Vue / ECharts / SheetJS
├─ tools/             开发与测试工具（截图、造数据、验收测试等）
├─ data/              运行数据（数据库 / 附件 / 备份）—— 不纳入版本管理
└─ CHANGELOG.md       变更记录
```

## 开发与测试

```bat
:: 启动服务（开发模式，前台运行便于看日志）
:: CRM_ROOT 指向本项目所在目录，CRM_PORT 可省略（默认 8899）
set CRM_ROOT=%~dp0
set CRM_PORT=8899
node server\server.js

:: 一键跑全部测试套件（会先清空业务数据，仅在空库/测试库上使用）
node tools\run-all-tests.js

:: 生成演示数据，便于看界面效果
node tools\seed-demo-data.js

:: 界面截图（输出到 .shots/）
node tools\screenshot.js --tag review
```

测试覆盖：**27 个套件 / 712 项断言**，包含真实浏览器（Chrome + Edge）交互实测
与本地模拟 IMAP 服务器上的完整采集流程。

> ⚠️ `tools/run-all-tests.js` 与 `tools/cleanup-test-data.js --all` 会**清空业务数据**，
> 是为验收测试设计的。库里已有真实数据时请勿直接执行。
